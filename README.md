!ExpenseTrack Dashboard

✨ Features
1. Dashboard Overview
View total income.
Monitor total expenses.
Check remaining account balance.
Calculate savings rate.
Get a quick overview of your financial status.
2. Add Transactions
Add new income or expense transactions.
Enter transaction names and amounts.
Select transaction categories.
Choose transaction dates.
Easily manage financial records.
3. Spending Breakdown
View monthly expenses.
Analyze category-wise spending.
Visualize expenses using a doughnut chart.
See the percentage of expenses spent in each category.
Filter spending data by reporting month.
4. Transaction History
View all recorded transactions.
Check transaction dates, names, categories, and amounts.
Filter transactions by type.
Delete unwanted transactions.
5. Financial Summary
The dashboard automatically displays:

Total Income: Sum of all income transactions.
Total Expenses: Sum of all expense transactions.
Remaining Balance: Income minus expenses.
Savings Rate: Percentage of income remaining after expenses.

🎯 Project Objective
The main objective of ExpenseTrack is to make personal financial management simple, organized, and accessible. It helps users understand where their money goes, track their savings, and make better financial decisions.
